# Printer hardware

This is the hardware I'm running on my VZBot 330 AWD, listed here as a reference alongside my configuration.

| Component | Specification |
| --- | --- |
| Printer | VZBot 330 AWD |
| Steppers | LDO 2504AC |
| Motion parts | All-metal CNC VZBot parts |
| Linear rails | LDO |
| X/Y endstops | Physical endstops |
| Hotend | Goliath |
| Nozzle | 0.4 mm |
| Extruder | Hextrudort |
| Filament path | End-to-end PTFE-tubed filament line |
| Part cooling | CPAP fan |
| RSCS cooling | RSCS fans |
| Enclosure | Full plexiglass enclosure |
| Probe | Cartographer |
| Chamber heater | PTC |
| Controller | Octopus Pro |
| Stepper drivers | TMC5160 Pro |
| Power supplies | Dual power supplies: 48 V for motor drive, 24 V for the remaining DC hardware |
| Host computer | Orange Pi 5 Pro |
| Heated bed | 240 V AC heated bed |

See the [README](README.md) for my configuration files. **Do not copy and paste my configuration onto another printer:** matching parts do not mean matching wiring or calibration.
